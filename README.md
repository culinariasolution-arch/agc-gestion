# AGC Construcciones · Gestión

PWA para llevar obras, gastos y cobros de AGC Construcciones. Los datos se guardan en Google Sheets a través de una API en Apps Script.

- `index.html`, `app.js`, `styles.css`: la app
- `config.js`: dirección de la API (la clave de acceso no está en el código, se escribe en la app)
- `sw.js`, `manifest.webmanifest`, `icons/`: instalación como app y funcionamiento sin conexión
